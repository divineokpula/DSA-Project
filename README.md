## Project Topic: E-commerce Analysis 

### Project Overview 

This Data Analysis project aims to generate insight into the sales performance of the e-commerce project over the past year. By analysing the various parameters in the data received, we seek to gather enough insight to make reasonable decisions, which then enable us to tell compelling stories around our data from the insights gained and to identify the best performance from our data

This documentation will enable us to make better decisions and tell a compelling story
